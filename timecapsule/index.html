One event, lasting memories

Capture the moment. Keep the memory.

QwerNFC TimeCapsule is an event photography and gallery service. An event organizer can assign a permanent QR/NFC link to a wedding, birthday, celebration or other event. Guests can use the link to capture photographs; approved photographs can later appear in the event's web gallery.

1. Connect storage

An authorized event owner connects their own Google Drive account to store their event photographs in a dedicated folder.

2. Guests take photos

Guests scan an event QR or NFC card to open the camera experience. Individual guest sessions support a limited number of photographs.

3. Review and share

The event manager reviews submissions before approved images are displayed on the TimeCapsule web gallery.

How Google Drive is used

The event owner's Google account is authorized through Google's permission screen. Our planned Drive integration uses limited Drive file access to create and manage the event's own photo folder and files. Guests do not receive the owner's Google credentials or unrestricted access to Drive.

TimeCapsule's cloud integration is being activated and tested. Public photo uploads and event galleries become available only after the event owner connects storage and the event is enabled.
